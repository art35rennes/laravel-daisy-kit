# v6.1.0 release validation

This record captures the acceptance evidence for the exact package and demo
commits published as `v6.1.0`. Historical validation records remain unchanged.

## Candidate

- Package source branch: `dev`.
- Audited package commit: `36b573dba0a198a36af088f2e37362782e9b4814`.
- Demo source branch: `dev`.
- Audited demo base commit: `83ceb8c`.
- Public surface: thirteen independent Blade, ESM and CSS modules.
- Distribution: immutable GitHub/VCS tags only, without Packagist or npm publication.

## Required gates

- Composer validation, Pint, PHPStan and 100% PHP type coverage.
- Reproducible tracked `dist/` output.
- Pest Feature, Unit and Browser suites without TIA.
- Vitest coverage and a fresh Composer/Vite consumer.
- Fresh TIA baseline as a supplementary check.
- Composer and npm security audits.
- Synchronized demo build and release suite against the exact package tag.
- Green GitHub workflows on the final commits and tags.

## Candidate evidence

- `composer validate --strict`, Pint and PHPStan pass on PHP 8.4.
- PHP type coverage is 100%.
- The tracked distribution rebuilds without a diff.
- Pest passes 138 Unit and Feature tests with 1,037 assertions, then 66 Browser
  tests with 546 assertions without TIA.
- Vitest passes 248 tests. Coverage is 86.75% statements, 74.84% branches,
  87.26% functions and 90.81% lines.
- The fresh Composer/Vite consumer and the supplementary fresh TIA baseline
  pass. The combined TIA run covers 204 tests with 1,583 assertions.
- Composer and npm report no known security vulnerability.
- A fresh clone of the demo resolves the exact package candidate commit, builds
  its Vite assets and passes 339 Feature and Architecture assertions plus 1,044
  Browser assertions.

Final tag identifiers, workflow links and remote immutability checks are added
to the GitHub Release after both repositories have passed their tag workflows.
