# Laravel Daisy Kit v6.0.0

Stable public release of eleven independently mounted Laravel UI modules for
PHP 8.4+ and Laravel 13. Install from the public GitHub VCS repository; this is
not a Packagist or npm publication.

## Breaking changes

Forms Viewer, Forms Builder and the package Livewire integration from v5.0.0
are removed. Applications own forms and any Livewire integration. No legacy
aliases, generic DaisyUI wrappers or compatibility layer are provided.
See [the upgrade guide](../upgrading-to-v6.md).

## Included

- Table, Tree, Blueprint, File Preview and Map with documented business workflows.
- Copyable, Combobox, Signature, Truncate, Scrollspy and Transfer List.
- Independent Blade/ESM/CSS entries, stable instance facades, structured errors,
  native form synchronization and explicit teardown.
- Rich suggestions, hierarchical search and pagination, assignment ordering,
  contextual text disclosure and accessible copy feedback.
- Tracked runtime distribution, a fresh Composer/Vite host test and an
  executable [demo repository](https://github.com/art35rennes/laravel-daisy-kit-demo/tree/v6.0.0).

## Installation

```json
{
  "repositories": [{ "type": "vcs", "url": "https://github.com/art35rennes/laravel-daisy-kit" }],
  "require": { "art35rennes/laravel-daisy-kit": "^6.0" }
}
```

Follow the [README](../../README.md) for the `@daisy-kit` alias and explicit JS/CSS
imports. Host applications compile Tailwind and DaisyUI themselves. No package
asset publishing, npm installation or package build is required by consumers.

## Limits and support

- Signature and Transfer List require `style-src-attr 'unsafe-inline'` because
  their dependencies write DOM styles. Other parent-page modules retain strict
  style-attribute CSP; File Preview has a separate sandbox policy.
- Native Clipboard access needs an eligible secure context and browser permission.
  Native popovers and other modern browser APIs require a current browser.
- Transfer List pages local assignments; it is not a virtualized remote dataset.
- Document previews support the documented formats and validation limits, not
  arbitrary Office files. Maps need host-approved tiles and attribution.
- Report bugs through GitHub issues with version, minimal example and browser
  diagnostics. Do not attach secrets or private documents.

Historical tags are immutable. Corrections after this release use a new patch tag.
