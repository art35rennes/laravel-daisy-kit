# Laravel Daisy Kit v5.1.0-alpha.2

> Préversion VCS — validation propriétaire en attente.

This immutable corrective development prerelease is for the rebuilt demo. It is not a stable
release, must be consumed through its exact VCS tag, and does not promote `main` or `dev`.

## Blueprint correction

- An editable `x-daisy-kit::blueprint` now keeps the public `value` graph synchronized with
  structural edits. Add, remove, transition, undo, redo, hidden JSON, and remount therefore all
  observe the same current graph instead of reloading the initial `value` snapshot.
- The correction is covered with value-backed unit, browser Workbench, and fresh Composer/Vite
  host-fixture flows, including isolated multiple instances.

## Deliberate boundary

This remains one corrective v5 development line. It provides no compatibility layer for v5.0.0
or historical v5 alpha tags, and it does not restore v4 aliases, generic DaisyUI wrappers,
charts, calendars, or application templates. `legacy/4.x` remains the frozen v4 line.
