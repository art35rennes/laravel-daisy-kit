# Laravel Daisy Kit v6.1.0

Stable public release of thirteen independently mounted Laravel UI modules for
PHP 8.4+ and Laravel 13. Install from the public GitHub VCS repository; this is
not a Packagist or npm publication.

## Added

- Code Editor provides a CodeMirror 6 editor with native form synchronization,
  lazy language grammars, localized controls, search, completion, folding and
  local on-demand formatting.
- WYSIWYG provides a Trix editor with native form synchronization, browser
  sanitization, host-coordinated attachments and a documented Trix escape hatch.

Both modules expose the standard `mount`, `mountAll`, `unmount` and `getInstance`
lifecycle and require explicit JavaScript and CSS imports.

## Corrected

- Scrollspy keeps navigation inside its configured scrollable content panel.
- Asynchronous Code Editor operations reject stale work without replacing newer
  content, and formatting remains undoable.
- WYSIWYG waits for host attachment coordination and releases pending browser
  resources during teardown.

## Installation

```json
{
  "repositories": [{ "type": "vcs", "url": "https://github.com/art35rennes/laravel-daisy-kit" }],
  "require": { "art35rennes/laravel-daisy-kit": "^6.1" }
}
```

Follow the [README](../../README.md) for the `@daisy-kit` alias and explicit
module imports. The matching executable demo is tagged
[`v6.1.0`](https://github.com/art35rennes/laravel-daisy-kit-demo/tree/v6.1.0).

## Security and CSP

- Code Editor does not execute, save or transmit edited code. Its generated
  CodeMirror styles require the documented response nonce.
- WYSIWYG sanitizes editor HTML in the browser, but hosts must sanitize submitted
  HTML again on the server. The package provides no upload route or storage.
- WYSIWYG, Signature and Transfer List require the narrow documented
  `style-src-attr 'unsafe-inline'` exception. WYSIWYG also needs the Trix style
  nonce and `img-src blob:` when local attachment previews are enabled.
- Historical tags remain immutable. Corrections after this release use a new
  patch version.
