# Laravel Daisy Kit v6.1.4

Security maintenance release for PHP 8.4.27+ / PHP 8.5.12+ and Laravel 13.

- Refresh compatible Composer and npm dependencies, including Vite 8.3.5 and
  Vitest/coverage-v8 4.1.12, and rebuild all tracked runtime assets.
- Require patched PHP and Node 24.22.1+, with reproducible npm lock files.
- Run CI on PHP 8.4/8.5 and Ubuntu 24.04, pin GitHub Actions to verified releases,
  and audit dependency locks weekly with Dependabot update configuration.
- Exclude eMudhra/emSign roots and the affected AAA Certificate Services
  cross-signing path before CI checkout or dependency downloads.
- Keep Larastan's view validation typed and make browser-test shortcuts portable
  between macOS and Linux. Module APIs and CSP contracts remain unchanged.

Consumers should update to `^6.1.4` from the Git VCS repository, run Composer and
host asset builds, and update their actual PHP interpreter and TLS trust stores.
A lock-file update alone does not update PHP-FPM or a server's root certificates.

The matching demo release locks this immutable tag. Planned breaking dependency
updates are recorded in [the maintenance report](../maintenance-2026-10-24.md).
