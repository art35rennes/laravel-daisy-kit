# Laravel Daisy Kit v5.1.0-alpha.1

> Préversion VCS — validation propriétaire en attente.

This immutable corrective development prerelease is for integration with the rebuilt demo. It is
not a stable release, must be consumed through its exact VCS tag, and does not promote `main` or
`dev`.

## Corrective contract

- Restores the differentiated product outcomes for Forms Viewer and optional Livewire 4 Builder,
  Table, Tree, Blueprint, File Preview, and Map.
- Keeps one canonical Builder-to-Viewer JSONata descriptor, explicit host Vite entries, host-owned
  Tailwind/DaisyUI, strict module CSP, idempotent mount lifecycle and no global bootstrap.
- Preserves the sandboxed File Preview frame without `allow-same-origin` and maintains browser
  coverage for real modal/focus behavior, Livewire authoring, keyboard controls and responsive
  host styling.

## Dependency and quality baseline

- Uses TanStack Table 9.2.3, jsdom 30.0.1, Laravel Boost 2.7.0, PHP 8.4 and Laravel 13; exact
  sources and locked versions are in
  [docs/dependencies.md](https://github.com/art35rennes/laravel-daisy-kit/blob/v5.1.0-alpha.1/docs/dependencies.md).
- The release gate is cache-independent (`composer test` / `composer test:full`); Pest 5 TIA is an
  additional local and CI acceleration, never a prerequisite for the full suite.
- Composer and production npm audits report zero advisories/vulnerabilities.

## Deliberate boundary

This is one corrective v5 development line. It deliberately provides no compatibility layer for
v5.0.0 or historical v5 alpha tags, and it does not restore v4 aliases, generic DaisyUI wrappers,
charts, calendars, or application templates. `legacy/4.x` remains the frozen v4 line.
