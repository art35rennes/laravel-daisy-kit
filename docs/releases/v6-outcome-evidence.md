# v6 outcome evidence

This is a static traceability review of the [v6 product contract matrix](../specs/v6-product-contract-matrix.md), not a record of a successful release run. Each row below follows one outcome row in that matrix, in the same order. It identifies existing assertions and their boundaries. Exact candidate commits, commands, results and publication checks belong in `v6-validation.md`.

Package paths are relative to this repository. Paths prefixed **demo:** are relative to the public [demo repository](https://github.com/art35rennes/laravel-daisy-kit-demo). Test titles are exact; where several tests contribute, the table names the principal outcome proofs. Shared lifecycle and responsive proofs apply to all module sections below.

## Review follow-through and remaining verification

The initial static review identified imported Signature image loss on resize, absent real Signature outcome tests, missing Table error/recovery and reload tests, missing read-only Blueprint browser proof, incomplete lifecycle browser coverage, and a missing three-theme demo matrix. The sources now contain targeted regressions for these findings. The associated runtime fix and final candidate still require the recorded release gates; this document deliberately does not label unexecuted suites as passing.

The new lifecycle dataset covers all 11 entries. The Table and Blueprint scenarios add business outcomes rather than only mount-state assertions. Signature now uses real browser drawing/imports and image-cancellation scenarios. The demo responsive dataset includes light, dark and cupcake; complete execution on its synchronized package reference remains part of release validation.

The narrower boundaries in the tables remain explicit: native-button/link semantics are not equivalent to dedicated keyboard tests; mocked adapters are not external service validation; enabled download controls are not byte-level download checks. These distinctions prevent the evidence inventory from claiming more than the assertions establish.
